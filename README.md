Online Food Delivery Analytics System
Project Overview
This project analyzes data from an online food delivery platform using SQL and MySQL. The system manages customer, restaurant, order, and delivery agent information and generates business insights through analytical SQL queries.

Objectives
Analyze customer ordering behavior
Track restaurant revenue and performance
Evaluate delivery efficiency
Identify business trends and patterns
Generate management-level insights
